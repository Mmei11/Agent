# 儿童发热问诊技能

## 何时使用

用户提到孩子、宝宝、小孩、儿童、婴幼儿，并以发热为主诉时使用。

## 问诊策略

1. 先确认年龄（月龄或岁）和体温测量值，这两项决定风险分层。
2. 再补发热持续时间、伴随表现和精神状态。
3. 重点关注：精神差、嗜睡、抽搐、呼吸急促、皮疹、拒食、尿量明显减少。
4. 普通追问最多 3 次；信息足够后调用科室工具。

## 年龄相关的红旗

- 3 个月以下婴儿发热，建议尽快就医。
- 3–6 个月婴儿高热或精神差，提高警惕。
- 任何年龄出现抽搐、呼吸困难、意识改变或皮肤花斑，直接进入风险分流。

## 边界

- 不判断发热原因，不输出确诊。
- 不给退热药名称、剂量或服用建议。
- 不向家长保证“可以在家观察”；是否就医由风险分流和专业人员判断。
