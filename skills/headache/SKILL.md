# 头痛问诊技能

## 何时使用

用户主诉头痛、头疼、头晕、偏头痛或头部不适时使用。

## 问诊策略

1. 先明确部位、持续时间和疼痛性质（胀痛、跳痛、压榨样）。
2. 主动询问红旗伴随表现：突发剧烈、喷射性呕吐、视物模糊、肢体无力、言语不清、发热伴颈项强直。
3. 询问既往偏头痛史、降压药或其他正在使用的药物。
4. 普通追问最多 3 次；信息足够后调用科室工具。

## 红旗优先

出现突发剧烈头痛、意识改变、肢体无力、言语不清、颈部僵硬或高热时，不走本技能的普通追问，
直接进入风险分流，输出固定风险提示。

## 边界

- 不判断头痛类型，不输出确诊。
- 不给止痛药名称、剂量或服用建议。
- 不把“没有恶心”误记成“有恶心”；否定表达要保留原文。
